# 年会大屏抽奖

一个功能丰富的年会/活动抽奖系统，支持大屏展示、多奖项管理。

## 特性

- **单文件部署**：构建后生成单个 HTML 文件，可直接用浏览器打开，无需服务器
- **演示翻页模式 (🆕)**：完美适配物理 PPT 翻页笔与键盘方向键 (`ArrowRight`/`Space`/`PageDown`)，提供大屏两侧悬浮金边手/键控切换及弹性液态页码指示舱，适合多人中奖舞台演示
- **2027 级全局奢华美学 (🆕)**：呼吸式暗金极光背景、漫天飞舞的金色星光粒子、白金金属渐变欢迎大字、暗光琉璃 3D 卡片及 Shimmer 金砂扫光流光特效，第一眼震撼全场
- **分奖项精准黑名单 (🆕)**：高阶受控模式支持单独为每个人配置禁止抽取哪些特定奖项（如禁中一等奖但允许三等奖），提供完全无痕的隐蔽后台控制与 CSV 批量导入支持
- **大屏展示**：精美的欢迎页、奖项页、抽奖页，支持全屏展示
- **两阶段滚动动画**：先滚动并定格奖品图片，再滚动并定格中奖者名字，带加速/减速效果；名字定格后播放可配置的庆祝特效与音效
- **多奖项管理**：支持自定义奖项名称、数量、奖品描述
- **数据持久化**：所有数据保存在浏览器本地，刷新不丢失

## 快速开始

### 方式一：直接使用（推荐）

1. 下载 `dist/index.html` 文件
2. 用浏览器打开即可使用
3. 访问 `index.html#/admin` 进入后台管理

### 方式二：本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

### 页面结构

| 路径 | 说明 |
|------|------|
| `#/` | 大屏展示页（用于投影/大屏幕） |
| `#/admin` | 后台管理页 |

### 后台管理

默认密码：`admin`（可在系统设置中修改）

**功能标签页**：
- **现场控制**：切换大屏场景、选择奖项、设置模块数，按四步推进两阶段抽奖（奖品滚动→定格，名字滚动→定格）
- **参与者**：导入 CSV、查看/编辑参与者列表
- **奖项管理**：添加/编辑/删除奖项
- **中奖记录**：查看历史中奖名单、导出记录
- **系统设置**：自定义标题、Logo、密码等

### CSV 导入格式

基础格式（两列）：

```csv
姓名,部门
张三,技术部
李四,市场部
王五,人事部
```

### 大屏操作

大屏页本身不接收按键，所有操作都在后台「现场控制」面板完成。主按钮依次推进四步：`开始抽奖品` → `停止 · 定格奖品` → `开始抽名字` → `停止 · 定格名字`，之后点 `下一轮`。后台窗口获得焦点（且焦点不在输入框）时，`空格键` 与主按钮作用相同。

## 两阶段奖品抽奖（2026-11）

每轮大屏显示若干模块（1–60 个，如 10 = 5×2、12 = 4×3）：第一次抽奖滚动并定格奖品图片，第二次抽奖在图片下方滚动并定格中奖者名字。

### 操作流程

1. 后台「图片池」批量上传奖品图片（可先填写分组，如「一等奖」；每张图片自动编号 `IMG-0001`）。
2. 「批量导入」导入名单（每人自动编号 `N-0001`）。
3. 「现场控制」选择奖项档位（按钮显示 `已抽/总数`）。
4. 设置本轮模块数（快捷按钮 `1 2 3 6 10 12`、`剩余全部`），可选择本轮参与的图片池与名字池。
5. 四次按键（后台主按钮或空格键）：`开始抽奖品` → `停止 · 定格奖品` → `开始抽名字` → `停止 · 定格名字`；之后点 `下一轮`。
6. 「大屏样式与特效」可即时调整名字/说明文字、模块大小与背景、中奖特效与音效，大屏约 0.5 秒内同步。音效只在大屏窗口播放，大屏需点击一次页面启用音频。

### 去重规则

- 同一轮内抽中的图片、名字不重复；已抽中的图片和名字在后续轮次不再出现。
- 唯一性按自动编号（内部 id）判断，同名不同人可并存，导入时会提示重名数量。
- 只有定格结果算作「已抽中」，滚动中闪过的不算。
- 已抽中或本轮已定格的图片不能删除（重置清零后可删）。
- 受控字段（必中、禁中、权重）仍作用于抽名字阶段。

### 图片存储与 file:// 兼容性

图片与自定义音频以 Blob 存放在浏览器 IndexedDB（库名 `lucky-draw-media`），名单、记录与设置仍在 localStorage。部分浏览器在 `file://` 下无法使用 IndexedDB，此时后台会显示警告。请使用 Chrome / Edge 打开，或执行 `pnpm preview` 通过 http 访问。清除浏览器数据会同时丢失图片。

### Excel 名单导入

不直接导入 `.xlsx`。可以：

- 将 Excel 另存为 CSV 后，在「批量导入」点「选择文件」（支持 `.csv` / `.txt` / `.tsv`，自动识别 UTF-8 与 GBK）；
- 或直接从 Excel 复制单元格粘贴到文本框（制表符分隔）。

支持每行一个姓名、`姓名,部门`，或带表头的 CSV。导入方式可选「覆盖现有名单」或「追加到现有名单」；已有抽奖记录时只能追加。

### 重置清零与清空数据库

| 操作 | 位置 | 清除内容 | 保留内容 |
|------|------|----------|----------|
| 重置清零 | 中奖记录 | 全部抽奖记录与当前轮次，所有图片和名字恢复可抽 | 图片池、名单、奖项、设置 |
| 清空数据库 | 批量导入 | 中奖记录、本轮状态、参与者名单（恢复为内置默认名单并重新编号）、奖项（恢复为初始奖项）、轮次计数归零 | 图片池、系统设置（样式/特效/音效） |

## 高级功能

通过 URL 参数 `?controlled=1` 解锁（注意参数要放在 `#` 之前）：

```
index.html?controlled=1#/admin
```

或本地开发时：
```
http://localhost:5173/?controlled=1#/admin
```

解锁后可使用：
- **必中奖项**：指定某人必中特定奖项
- **禁止中奖**：将某人加入黑名单
- **权重设置**：调整中奖概率（1-10）

### 高级功能 CSV 格式

```csv
姓名,部门,必中奖项(奖项名称),禁止中奖(是/否),权重(1-10)
张三,技术部,一等奖,,
李四,市场部,,是,
王五,人事部,,,5
```

## 技术栈

- React 19 + TypeScript
- Tailwind CSS v4
- Zustand（状态管理）
- Framer Motion（动画）
- Wouter（路由，支持 hash 模式）
- Vite + vite-plugin-singlefile（单文件构建）

## 数据存储

所有数据存储在浏览器本地：

| 存储类型 | 内容 | 说明 |
|---------|------|------|
| localStorage | 参与者、奖项、中奖记录、设置 | 持久保存 |
| sessionStorage | 登录状态 | 关闭浏览器后失效 |

**注意事项**：
- 后台和大屏需在**同一浏览器**中打开才能同步
- 清除浏览器数据会丢失所有记录
- 密码为明文存储，仅作为简单防误触保护
